# Сайт ведущего Леонида Дамбиева

Одностраничный сайт на **React 19 + TypeScript + Vite**. HTML пререндерится при сборке (весь текст виден поисковикам сразу), форма заявки отправляет данные в **Telegram** через серверную функцию — токен бота не попадает в браузер.

## Быстрый старт

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # проверка типов → сборка → пререндер в /dist
npm run validate   # проверка валидности HTML
npm run preview    # посмотреть собранную версию
```

Нужен Node.js 20+.

## Где менять тексты, фото и контакты

Всё наполнение — в одном файле: **`src/content.ts`**.
Места с пометкой `ЗАГЛУШКА` — данных не было на старом сайте, их нужно заменить:

| Что | Где в `content.ts` |
|---|---|
| Город (для SEO-заголовков) | `site.city`, `site.cityIn` |
| Цифры «лет / праздников» | `about.facts` |
| Отзывы (сейчас образцы с пометкой) | `reviews` — уберите `placeholder: true` у реальных |
| Ник в Telegram | `contacts.telegram` |
| Домен сайта | переменная `VITE_SITE_URL` в `.env` |

Когда в `reviews` останутся только реальные отзывы, они автоматически попадут в микроразметку Schema.org.

## Фото

У каждого фото в `src/content.ts` свой источник: `tilda` — картинка со старого сайта, `widths` — своё фото из `public/img/`.

Чтобы добавить или заменить своё фото:

1. Положите обработанный исходник в `photos-src/` (папка не попадает в git), например `photos-src/hero.png`.
2. Пропишите ширины в `scripts/optimize-images.mjs` и запустите `npm run images` — появятся AVIF + WebP в `public/img/`.
3. В `src/content.ts` у этого фото укажите те же `widths` и пропорции `ratio`.

Картинки грузятся лениво, с `srcset`/`sizes`, фиксированными пропорциями (нулевой сдвиг вёрстки) и аккуратной заглушкой, если файл недоступен.

## Форма → Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Напишите боту любое сообщение (или добавьте его в группу) и откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — возьмите `chat.id`.
3. Подключите один из вариантов:

**Vercel (рекомендуется).** Функция уже лежит в `api/lead.ts`. В настройках проекта добавьте переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Build command: `npm run build`, output: `dist`.

**Обычный PHP-хостинг (Beget, Timeweb, REG.RU).** В `.env` укажите `VITE_LEAD_ENDPOINT=/lead.php`, соберите проект и загрузите содержимое `dist/` в корень сайта. Токен положите в файл `lead-config.php` уровнем выше корня сайта:

```php
<?php return ['token' => '123456:ABC...', 'chat_id' => '123456789'];
```

Что обрабатывается: проверка полей на клиенте и на сервере, маска телефона, таймаут 15 с, нет интернета, ошибка сервера, сбой Telegram, лимит 5 заявок за 10 минут с одного IP, ловушка для спам-ботов, сохранение черновика (данные не теряются при ошибке или перезагрузке) и запасная кнопка «Отправить в WhatsApp» с уже заполненным текстом заявки.

## GitHub Pages (демо)

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт при каждом пуше в `main`. Один раз включите в репозитории **Settings → Pages → Source: GitHub Actions**.

На Pages сайт работает в демо-режиме: форма показывает успешную отправку, но никуда не шлёт (на Pages нет сервера), а страница закрыта от поисковиков. Для боевого запуска подключите репозиторий к Vercel (форма заработает сразу) или уберите `VITE_DEMO` и `VITE_NOINDEX` из workflow и укажите `VITE_LEAD_ENDPOINT` на свой сервер.

## Что внутри

- **Первый экран:** диско-шар на canvas — блики разлетаются по экрану, курсор работает как прожектор; буквы имени «пританцовывают» рядом с курсором (на телефоне — волной по тапу); арка с фото поворачивается за мышью.
- **Анимации:** появление блоков при скролле, параллакс фото и галереи, плавающее превью фото у курсора в списке форматов, линия-прогресс в шагах работы, конфетти после отправки заявки. Всё отключается при системной настройке «уменьшить движение» и останавливается, когда блок не на экране.
- **Адаптив:** телефон (от 320 px), планшет, десктоп. На телефоне — нижняя панель «Позвонить / WhatsApp / Telegram / Заявка».
- **SEO:** пререндер HTML, title/description/keywords, Open Graph, canonical, микроразметка `Person`, `ProfessionalService`, `FAQPage`, `sitemap.xml`, `robots.txt`, одна `h1`, семантические заголовки, alt у фото.
- **Скорость:** без тяжёлых библиотек анимации, шрифты хостятся локально только нужными наборами символов, предзагрузка главного фото. Lighthouse (мобильный): производительность 98, SEO 100.
- **Валидность и кроссбраузерность:** проверено html-validate и W3C Nu Validator без ошибок; autoprefixer, цели сборки — Chrome/Edge 90+, Firefox 90+, Safari 14+ (iOS 14+).
- **Доступность:** навигация с клавиатуры, видимый фокус, aria-атрибуты у слайдера и формы, ссылка «Перейти к содержимому».

## Структура

```
src/
  content.ts            ← все тексты, контакты, фото, SEO
  components/           ← секции страницы (каждая со своим CSS)
  lib/mirrorball.ts     ← диско-шар на canvas
  lib/motion.ts         ← появление при скролле, параллакс, конфетти
  lib/validation.ts     ← общая валидация заявки (клиент + сервер)
  lib/sendLead.ts       ← отправка формы и обработка ошибок
  entry-server.tsx      ← пререндер и мета-теги
api/lead.ts             ← серверная функция для Vercel
public/lead.php         ← то же для PHP-хостинга
public/privacy.html     ← политика конфиденциальности (шаблон — заполните реквизиты)
scripts/                ← пререндер и оптимизация фото
```
